SKILLFORGE ACADEMY — GITHUB UPLOAD PACKAGE
==========================================

This folder contains the complete source code for the current SkillForge Academy build.

CONTENTS
- index.html: main academy dashboard and original WordPress Fundamentals course.
- README.txt: project overview, publishing notes and tool/licensing cautions.
- courses/index.html: expanded learning-path catalogue.
- courses/<course-name>/index.html: complete lesson pages, presentation navigation,
  lesson content and course-specific guided simulation code.
- courses/<course-name>/README.md: course folder notes.

THE 9 EXPANDED LEARNING PATHS
1. Figma Foundations
2. Figma to WordPress Workflow
3. Elementor Page Builder
4. UI/UX Design
5. HTML, CSS and JavaScript
6. GitHub and Netlify Deployment
7. Forms, Google Sheets and Automations
8. Performance, SEO and Accessibility
9. WooCommerce and Course Enrollment

SIMULATIONS
Each expanded course includes a guided simulated software workspace:
- step-by-step task instructions
- course-specific simulated menus and controls
- clickable practice actions
- correct/incorrect action feedback
- task progress indicator
- reset control

These are training replicas inspired by common software workflows. They are not official
Figma, WordPress, Elementor, GitHub, Netlify, Google Sheets or WooCommerce interfaces
and do not connect to real accounts.

UPLOAD TO AN EXISTING GITHUB REPOSITORY
1. Extract this ZIP on your computer.
2. Open the extracted SkillForge-Academy-GitHub-Upload folder.
3. Open your existing GitHub repository.
4. Choose Add file > Upload files.
5. Drag the CONTENTS of this folder into the upload area:
   index.html, README.txt, and the courses folder.
6. If GitHub asks about replacing existing files, replace them with these updated versions.
7. Commit the changes.

IMPORTANT: Upload the contents of this folder, not the ZIP file itself. Keep index.html
at the repository root so the static website has a homepage.

NETLIFY STATIC DEPLOYMENT
For this plain HTML/CSS/JavaScript project:
- Build command: leave blank.
- Publish directory: repository root (the folder containing index.html).
- This static academy can be hosted on Netlify.
- A real WordPress installation is separate and needs WordPress hosting or LocalWP;
  WordPress itself cannot run as a static Netlify site.

No Node.js, npm, React or build step is required for this project.
