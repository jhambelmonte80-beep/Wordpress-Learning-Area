UI/UX for Business Websites

Design usable, accessible and conversion-focused pages

Tools: Figma + usability principles

What you will master

  • Distinguish user interface (UI) from user experience (UX).
  • Define audience, primary task and conversion goal for each page.
  • Create a simple sitemap and user flow.
  • Use visual hierarchy, readable typography and consistent spacing.
  • Design clear forms, labels, errors and confirmation states.
  • Apply accessibility basics: contrast, keyboard access, labels and alt text.
  • Test with realistic tasks and improve based on observed friction.
