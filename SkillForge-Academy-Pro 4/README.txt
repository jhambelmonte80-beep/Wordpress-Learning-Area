SKILLFORGE ACADEMY — EXPANDED PROJECT
====================================

START HERE
1. Open index.html for the original WordPress Fundamentals academy dashboard.
2. Open courses/index.html for the expanded learning paths.
3. Each course has its own folder and index.html lesson page.

Each course folder includes:
- index.html: lesson page with objectives, practical steps, interactive simulation, client scenario and knowledge check.
- README.md: quick folder guide.

SIMULATIONS
The simulations are simplified training replicas. They do not connect to real Figma, WordPress, Elementor, Google Sheets, GitHub or payment accounts. Use them to rehearse decisions, then complete the same task in the actual software.

IMPORTANT TOOL/LICENSING NOTES
- Figma has free and paid plans; check current limits before client work.
- WordPress.org software is free, but hosting, domain names, premium themes/plugins and some services can cost money.
- Elementor Free and Elementor Pro are different. Pro-only requirements must be checked against the current plan and client license.
- Use LocalWP or a staging site to practice WordPress safely.
- Never enter real payment details in a practice simulation. Use payment gateway test mode.
- Keep passwords, API keys and client personal data out of public GitHub repositories.

PUBLISHING
For a static demo, publish the folder containing the root index.html through Netlify. The course pages are ordinary HTML files and work as static pages. A real WordPress installation is separate and needs WordPress hosting or a local WordPress environment; it cannot run as a static Netlify site.

SUGGESTED LEARNING ORDER
1. HTML/CSS/JavaScript foundations
2. UI/UX and Figma foundations
3. Figma-to-WordPress workflow
4. WordPress fundamentals (original dashboard course)
5. Elementor builder
6. Forms and integrations
7. Performance, SEO and accessibility
8. WooCommerce and course enrollment
9. GitHub/Netlify for publishing static demos and portfolio assets

PRESENTATION MODE: Each expanded lesson opens as a slide-style presentation. Navigate with Previous/Next, the slide outline, or keyboard arrow keys. All lesson sections remain included; longer slides can scroll. Print mode lays out all slides.
